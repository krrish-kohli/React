# 📋 Forms Handling Project

A practical demonstration of robust form management in React. This project focuses on efficiently handling multiple input fields, managing form state, and implementing controlled components with a clean and scalable approach.

## 🚀 Features

- **Multi-input State Management**: Single state object to manage various form fields.
- **Controlled Components**: Precise control over form data and UI synchronization.
- **Dynamic List Rendering**: Real-time updates as new data is submitted.
- **Form Validation**: Core logic for handling user input and submission.

## ⚙️ Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/krrish-kohli/React.git
   ```
2. Navigate to the project directory:
   ```bash
   cd practice-projects/forms-handling-project
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the development server:
```bash
npm run dev
```
Open `http://localhost:5173` in your browser to view the application.
