# Light-Dark Mode Project

A sleek and interactive React application featuring a seamless theme toggle. This project demonstrates the implementation of light and dark modes, focusing on user preference persistence and dynamic styling.

## Features

- **Theme Toggling**: Instant switching between light and dark visual modes.
- **Persistent Settings**: Remembers the user's theme choice across sessions (via localStorage).
- **Smooth Transitions**: CSS-driven animations for a polished user experience.
- **Accessible Design**: High-contrast dark mode for better readability in low-light environments.

## Tech Stack

- **React**: For UI state management.
- **Vite**: Ultra-fast build and development tool.
- **CSS Variables**: For efficient and maintainable theme styling.

## Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`.
3. Start the dev server: `npm run dev`.
